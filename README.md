# Mahbub Hussain — Personal Portfolio

A responsive, bilingual (English/Bangla) personal portfolio website with a premium black-and-gold visual theme.

## Files
- `index.html` — page structure and content
- `style.css` — responsive styling
- `script.js` — language switcher, mobile navigation and current year
- `images/` — add your own profile photo and project images here

## Preview locally
Open `index.html` in a modern browser. An internet connection is needed for Google Fonts.

## Publish with GitHub Pages
1. Sign in to GitHub.
2. Create a **public** repository named `mahbubkanaighat.github.io` (only if that username is available and belongs to you).
3. Upload `index.html`, `style.css`, `script.js`, and the `images` folder to the repository root.
4. Open **Settings → Pages**.
5. Under Build and deployment, choose **Deploy from a branch**.
6. Select branch `main` and folder `/ (root)`, then Save.
7. Wait for GitHub Pages to publish the site. The URL will be `https://mahbubkanaighat.github.io/` if the repository name is accepted.
